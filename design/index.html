KUMBIDA · DESIGN REFERENCE

What the product should look like

Open any screen to use it as a working prototype. These pages are the visual spec: match them when building the app. Details in CLAUDE.md and Kumbida-design.md.

The design gallery inside the landing page, booking page and admin Templates screen still shows an earlier list of designs. The current designs are the 31 below, grouped into these categories.

Website and system screens

  • Landing pagePublic website home: hero, how it works, designs gallery with preview modal, packages, FAQ, contact.
  • Booking page (/book)Package, event, design picker with preview, contact details, disabled Send with to-do list, confirmation.
  • Admin log-inEmail + password with optional 2-step code (demo code 123456), forgot password.
  • Admin invite sign-upTeam member creates an account from an invite link.
  • Admin dashboard (/admin)Overview, events, payments to verify, setup queue, templates (with preview), settings.
  • Host link: Pay stepPhone view: amount, UnionBank QR, receipt upload with automatic reading, submit rules, status.
  • Flow simulationEnd-to-end demo: client books and pays, admin confirms, host sets up. Reference for the flow, not a real screen.
